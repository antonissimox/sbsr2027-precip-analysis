# Validação Espacial do GPM IMERG V07 em Goiás, Brasil

Este repositório reúne rotinas computacionais para o processamento e a avaliação de estimativas de precipitação por satélite em comparação com observações pluviométricas de superfície.

O fluxo de trabalho contempla:

- Preparação e controle de qualidade dos dados;
- Pareamento temporal entre estimativas e observações pluviométricas;
- Avaliação estatística do desempenho do produto de precipitação;
- Análise espacial dos indicadores de desempenho em relação a covariáveis geográficas.

## Fontes de dados

- **GPM IMERG Final Run V07:** estimativas de precipitação por satélite;
- **CEMADEN:** observações pluviométricas de superfície;
- **Covariáveis geográficas:** informações utilizadas nas análises espaciais.

O repositório documenta os procedimentos computacionais empregados no processamento e na análise dos dados. A documentação metodológica complementar e os resultados científicos serão disponibilizados conforme o processo de publicação do estudo.
